魔方 GO 隐私政策

最后更新：2026年7月

欢迎使用 魔方 GO（以下简称"本应用"）。 我们深知个人信息对您的重要性，并尊重和保护您的隐私。 本隐私政策旨在说明本应用在您使用过程中如何处理您的信息，以及您所享有的相关权利。

请您在使用本应用前仔细阅读本隐私政策。 继续使用本应用，即表示您已阅读并理解本隐私政策。

适用范围

本隐私政策适用于魔方 GO 移动应用程序及相关功能。 如未来新增涉及个人信息处理的新功能，我们将在功能上线前同步更新本隐私政策。

个人信息处理说明

截至当前版本，魔方 GO 无需注册账号，也不会主动收集、上传或存储您的个人信息，包括但不限于：

  • 姓名
  • 手机号码
  • 电子邮箱地址
  • 身份证件信息
  • 家庭住址
  • 通讯录
  • 位置信息
  • 生物识别信息

除本隐私政策明确说明的功能外，我们不会收集任何能够识别您身份的个人信息。

GO 训练

魔方 GO 提供 GO 训练功能，支持通过 Universal Links、App Links、URL Scheme 等方式分享训练。

分享功能仅生成包含训练标识符的链接，用于在不同设备之间开始同一次训练。

分享链接不会包含您的身份信息、解法记录或其他个人信息，也不会上传至开发者运营的服务器。

本地存储

为了实现应用功能，本应用会在您的设备本地保存部分数据，包括但不限于：

  • 应用设置
  • 计时记录
  • 训练数据
  • 用户昵称
  • 公式集合
  • 练习内容
  • 其他由用户主动创建的数据

上述数据均保存在您的设备本地，不会上传至开发者服务器。

权限说明

为了实现部分功能，魔方 GO 可能会申请以下系统权限。所有权限均仅在您主动使用对应功能时申请，您可以自行决定是否授权。


相机权限

相机权限仅可能用于：

  • 扫描二维码
  • 识别实体魔方
  • 拍摄魔方贴纸图片

相机拍摄的内容仅在您的设备本地处理，不会上传至开发者服务器。


相册权限（照片权限）

相册权限仅可能用于：

  • 选择二维码图片
  • 选择魔方贴纸图片

您选择的图片仅用于实现对应功能，所有处理均在本地完成，不会上传至开发者服务器。

网络访问

本应用可能会使用网络连接完成以下功能：

  • 访问官方网站及隐私政策页面

网络访问不会用于上传您的本地数据，也不会用于收集您的个人信息。

第三方 SDK

截至当前版本，魔方 GO 未集成任何用于广告、统计分析、用户画像、消息推送或数据采集的第三方 SDK。

如未来新增第三方 SDK，我们将在应用更新前同步更新本隐私政策，并说明：

  • SDK 提供方名称
  • 收集的信息类型
  • 使用目的
  • 处理方式

个人信息共享

由于魔方 GO 不建立用户账号，也不运营存储用户数据的服务器，因此我们不会出售、出租、交易或向任何第三方共享您的个人信息。

除法律法规另有规定外，我们不会向任何组织或个人披露您的本地数据。

信息安全

本应用采用本地数据存储方式，避免将用户数据上传至开发者服务器，从设计上降低数据泄露风险。

请您妥善保管自己的设备，并注意系统安全设置，以避免因设备遗失、损坏或被他人获取而导致本地数据泄露。

广告与统计分析

截至当前版本，魔方 GO 不会：

  • 展示任何形式的广告
  • 使用广告标识符（Advertising ID、OAID 等）
  • 集成统计分析服务
  • 使用用户行为分析服务
  • 使用跟踪技术
  • 向第三方共享用户数据

如未来新增上述功能，我们将在功能上线前更新本隐私政策，并依法征求您的同意（如适用）。

您的权利

由于本应用采用本地数据存储方式，您始终拥有对本地数据的控制权。您可以根据需要：

  • 查看应用内保存的数据
  • 修改应用设置及用户昵称
  • 删除计时记录、训练数据、公式集合及其他用户生成内容
  • 卸载应用或清除应用数据，以删除全部本地数据

开发者无法访问、恢复或导出您设备中的本地数据。

数据存储与删除

魔方 GO 不建立用户账号，也不保存用户数据副本。 所有数据均保存在您的设备本地。

数据保留期限由您自行决定。您可以随时删除应用内数据，或通过系统设置清除应用数据，也可以直接卸载应用删除全部本地数据。

数据删除后将无法恢复，请您谨慎操作。

未成年人保护

魔方 GO 并非专门面向未成年人设计，但任何年龄段用户均可使用本应用。

我们不会主动收集未成年人的个人信息。如监护人发现未成年人在使用过程中存在涉及个人信息保护的问题，可通过本隐私政策提供的联系方式与我们联系，我们将依法处理。

隐私政策更新

我们可能根据法律法规、产品功能或运营需要对本隐私政策进行更新。

更新后的隐私政策将在本页面公布，并自公布之日起生效。对于涉及个人信息处理方式发生重大变化的，我们将通过适当方式向您提示。

联系我们

如果您对本隐私政策或个人信息保护有任何疑问、意见或建议，可通过以下方式联系我们：

  • 电子邮箱：privacy@mofanggo.com
  • 官方网站：https://mofanggo.com

我们将在收到您的反馈后，在合理期限内予以回复。
