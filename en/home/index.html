Official Rules & Guide
⚡ What is GO
GO is a synchronized cube battle mode where players solve under the same scramble across multiple devices.
🎯 Core Rules
  • All players receive identical scramble
  • Each GO session produces a single comparable result
  • Early exit is treated as completed attempt
  • Results are ranked by solve time
🧩 How It Works
  • Organizer creates GO session
  • Participants join via code or QR
  • All devices start simultaneously
  • System records time + moves
  • Final ranking generated automatically
⚠️ Important Notes
  • Do not refresh during active session
  • Network delay may affect sync start timing
  • Each GO.id can only be completed once
💡 Pro Tips
Use consistent solving habits for better ranking stability. Focus on inspection time and finger tricks.
